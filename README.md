# Kişisel Web Sitesi

HTML, CSS ve JavaScript ile geliştirilen kişisel portfolyo sitesi.

## Özellikler
- Koyu/açık tema desteği (localStorage ile kalıcı)
- Erişilebilir proje slider'ı (klavye, `inert`, `prefers-reduced-motion`)
- Sertifika görüntüleyici (`<dialog>` modal)
- Fetch ile API denemeleri
- Lighthouse: 100/100/100/100

## Teknolojiler
Semantik HTML, CSS Grid & Flexbox, vanilla JavaScript

## Yerel çalıştırma
Depoyu indirin ve `index.html` dosyasını tarayıcıda açın.
